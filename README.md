# Studious Engine

This repository contains a scaffolded Jekyll site generated on 2026-01-19. It includes a Gemfile using the GitHub Pages gem, a simple site configuration, and five example posts inspired by contemporary news themes.

To preview locally:

1. Install bundler: `gem install bundler`
2. Install dependencies: `bundle install`
3. Serve locally: `bundle exec jekyll serve`

Notes:
- The site is pushed to the `gh-pages` branch so it can be used as a GitHub Pages source. If Pages is not automatically enabled, go to the repository Settings → Pages and set the source to the `gh-pages` branch.
